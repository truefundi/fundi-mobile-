# Fundi Mobile App — Complete UI/UX Design Prompt

Design and build a **professional, modern mobile application UI for “Fundi”**, an on-demand skilled-worker marketplace that connects customers with qualified technicians such as mechanics, electricians, plumbers, HVAC technicians, appliance repair specialists, garage technicians, truck mechanics, and general maintenance workers.

The application must feel **trustworthy, practical, fast, professional, and easy to use**.

The core Fundi experience is:

**REQUEST → MATCH → ACCEPT → PAY VISIT FEE → TRACK → ARRIVE → DIAGNOSE → QUOTE → APPROVE → REPAIR → COMPLETE → PAYMENT → RATE**

---

# IMPORTANT DESIGN RULE

## ABSOLUTELY NO GRADIENTS

Do not use gradients anywhere in the application.

Do NOT use:

* Linear gradients
* Radial gradients
* Gradient backgrounds
* Gradient buttons
* Gradient cards
* Gradient overlays
* Gradient illustrations
* Gradient text
* Gradient icons

Use **solid colors only**.

The interface should rely on:

* Solid color backgrounds
* White surfaces
* Neutral backgrounds
* Clear borders
* Subtle shadows
* Strong typography
* Consistent spacing
* Simple icons
* Clear hierarchy

Keep the design clean and professional rather than flashy.

---

# DESIGN DIRECTION

Create a premium but practical service marketplace similar in usability to modern mobility and service applications.

The design should communicate:

**Trust + Speed + Reliability + Professionalism**

Avoid making it look like a generic food-delivery application.

The application should feel appropriate for:

* Car repairs
* Electrical work
* Plumbing
* HVAC
* Home maintenance
* Appliance repair
* Commercial equipment
* Emergency services

---

# COLOR SYSTEM

Use a solid-color design system.

Primary brand color:

---

# TYPOGRAPHY

Use a modern sans-serif font such as:

**Inter**

Typography should have a clear hierarchy:

* Large page titles
* Medium section headings
* Strong card titles
* Comfortable body text
* Small metadata labels
* Clear button labels

Use bold typography for important prices, statuses, and actions.

---

# GENERAL UI STYLE

Use:

* Rounded cards
* Medium corner radius
* Clean white surfaces
* Subtle borders
* Very subtle shadows
* Spacious layouts
* Large touch targets
* Clear primary CTA buttons
* Bottom navigation
* Simple line icons

Avoid:

* Excessive shadows
* Glassmorphism
* Neumorphism
* Excessive rounded/pill UI
* Excessive decorative elements
* Clutter
* Gradient effects
